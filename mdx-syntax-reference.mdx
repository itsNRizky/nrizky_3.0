### React / JSX / TSX

```tsx
// React component example
import { useState } from 'react';

interface ButtonProps {
  label: string;
  onClick: () => void;
}

export default function Button({ label, onClick }: ButtonProps) {
  const [isHovered, setIsHovered] = useState(false);

  return (
    <button
      onClick={onClick}
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      className={isHovered ? 'btn-hover' : 'btn'}
    >
      {label}
    </button>
  );
}
```

### SQL

```sql

  id SERIAL PRIMARY KEY,
  slug VARCHAR(255) UNIQUE NOT NULL,
  title VARCHAR(255) NOT NULL,
  content TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

ORDER BY created_at DESC
```

## Combining Elements

> **Note:** You can combine multiple elements:
>
> - Use `code` inside lists
> - Add **bold** or *italic* text
> - Include [links](https://example.com)

### Complex Example

Here's a real-world example combining multiple elements:

1. First, install the package:
   ```bash
   npm install gray-matter
   ```

2. Then, create the helper function:
   ```typescript
   import matter from 'gray-matter';

   export function parseArticle(content: string) {
     const { data, content: body } = matter(content);
     return { meta: data, body };
   }
   ```

3. Finally, use it in your component:
   ```tsx
   const article = parseArticle(fileContent);
   console.log(article.meta.title);
   ```

> **Result:** You now have a working MDX parser!
